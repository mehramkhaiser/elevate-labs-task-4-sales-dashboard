# Superstore Sales Performance Dashboard

**Elevate Labs Data Analyst Internship | Task 4**

## Project Overview
This project presents an interactive sales dashboard built using Google Looker Studio to analyze Superstore sales performance, profitability, product categories, and regional distribution.

## Tools Used
- Google Looker Studio
- Google Sheets
- Microsoft Excel
- GitHub

## Dataset
Superstore sales dataset containing order dates, product categories, regions, sales, profit, quantity, and other order details.

## Dashboard Features
- **Key Performance Indicators:** Total Sales, Total Profit, and Total Quantity Sold
- **Sales Trend:** Time-series visualization of sales over time
- **Category Analysis:** Comparison of sales across Furniture, Office Supplies, and Technology
- **Regional Analysis:** Sales distribution across regions
- **Interactive Filters:** Category, Region, and Date Range controls
